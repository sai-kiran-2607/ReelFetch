# ReelFetch — Official Landing Website Workspace

This workspace hosts the standalone official landing website for **ReelFetch (Instagram Reels Saver)**.

The website is maintained in the [`reelfetch-website/`](./reelfetch-website) folder, outside the mobile app codebase.

## Quick Start

```bash
cd reelfetch-website
npm install
npm run dev
```

For full details regarding the architecture, verified features, APK configuration, and production deployment, please refer to:
👉 [**reelfetch-website/README.md**](./reelfetch-website/README.md)
